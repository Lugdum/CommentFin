Apply to existing users

Saving above only changes the defaults for new users and for anyone who has never touched a given setting. This button resets every user's overlay settings, including people who already customised their own, so that they all follow the defaults above again. It takes effect for each user on their next page load.

Per-user access

Turn the comment overlay on or off for one person (they can still change it back themselves in the player), or block the plugin for them entirely. Blocking hides the overlay, the compose button and the library badges for that user and stops the server accepting comments from them; comments they have already posted stay visible. Changes take effect on that user's next page load.
